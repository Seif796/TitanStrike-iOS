# 🛡️ CyberFort: Titan Strike 3D (حصن السايبر: صائد العمالقة)

لعبة أكشن وبناء وتختيم جماعي ثلاثية الأبعاد (3D Co-op Fortress Building & Boss Hunt) تعمل بالعرض (Landscape) بالكامل، مصممة لهواتف **iPhone (iOS)** وأجهزة الكمبيوتر، مع دعم تصدير وبناء تلقائي لملف **IPA** عبر **GitHub Actions**.

---

## 🌟 أبرز الإضافات والمميزات الجديدة (New Features):

1. **نظام البناء ثلاثي الأبعاد (3D Base Building):**
   - إمكانية التحويل بضغطة زر بين طور القتال (Combat) وطور البناء (Build Mode).
   - بناء **جدران دفاعية (Defense Walls)** لصد ضربات الوحش ومقذوفاته النارية.
   - بناء **منحدرات وسلالم تكتيكية (Ramps)** للارتقاء للأماكن المرتفعة وقنص الوحش.
   - بناء **أبراج دفاعية آلية (Auto-Turrets)** تطلق ليزر أوتوماتيكياً على الوحوش المقتربة.
   - معاينة هولوغرام قبل البناء مع مزامنة البناء أونلاين فوراً لكل أعضاء الفريق.

2. **تصميم بالعرض الكامل (Locked Landscape):**
   - الشاشة مقفلة بالعرض بنسبة 16:9 مع دعم كامل لشاشات الآيفون وحواف الشاشة (Safe Area).

3. **نظام الغرف السهل (Create Room / Join Room):**
   - زر واضح ومباشر لـ **Create Room (إنشاء غرفة)**.
   - زر مباشر لـ **Join Room (انضمام لغرفة)**.
   - رسائل صوتية وإرشادية واضحة للخطوات.

4. **بدء المعركة تلقائياً بمجرد الدخول (Auto-Launch Match):**
   - بمجرد انضمام أي لاعب إلى الغرفة، يبدأ عد تنازلي تلقائي (3.. 2.. 1..) وتبدأ المعركة مباشرة بدون تعقيد!

5. **شخصيات محسّنة مع أنيميشن حركي كامل (Fluid Character Animation):**
   - حركة أرجل ديناميكية أثناء المشي والجري (Walking cycle).
   - حركة تنفس وهزّة جسم واقعية، وميلان الجسم عند الانعطاف (Banking/Leaning).
   - دروع وسترات سايبر مستقبلية ومفاعلات طاقة مضيئة ونفاثات طيران (Jetpack).
