# 🎮 TitanStrike 3D Co-op (لعبة صيد الوحش التعاونية)

لعبة أكشن وتختيم جماعي ثلاثية الأبعاد (3D Co-op Boss Hunt) مصممة ومجهزة للعمل على هواتف **iPhone (iOS)** والكمبيوتر (PC).
تتضمن اللعبة نظام تصدير وبناء تلقائي لملف **IPA** عبر **GitHub Actions** ليتم تثبيته مباشرة على جهاز الآيفون.

---

## 🌟 مميزات اللعبة (Features)

1. **لعب تعاوني أونلاين ومحلي (Multiplayer Co-op):**
   - يدعم اللعب الجماعي حتى 4 لاعبين.
   - إمكانية استضافة سيرفر (Host) بنقرة واحدة ومشاركة الآي بي (Local Wi-Fi IP) مع أصدقائك للاتصال معك مباشرة (Join).
   - نظام إنعاش الفريق (**Co-op Revive**): إذا سقط زميلك في المعركة، يمكنك الاقتراب منه والضغط على "Revive" لإنقاذه قبل خسارة الفريق!

2. **الشخصيات والأسلحة (Classes & Weapons):**
   - **Assault (المقتحم):** متوازن السرعة والصحة (120 HP)، يمتلك بندقية نبضات هجومية سريعة (Assault Pulse Rifle) ومسدس طاقة احتياطي.
   - **Heavy (المدرّع):** طاقة وصحة ضخمة (200 HP)، مدفع بلازما ثقيل وطلقات مدمرة لامتصاص هجمات الوحش.
   - **Scout (القناص):** رشيق وسريع جداً (90 HP)، بندقية قنص دقيقة لإحداث ضرر حرج في نقاط ضعف الوحش.

3. **نظام التختيم والوحش الرئيسي (Campaign & Titan Boss):**
   - **المرحلة الأولى والثانية (Wave Survival):** مواجهة موجات من الطائرات والعناكب الآلية التابعة للوحش (Minion Crawlers).
   - **معركة الوحش النهائي (Titan Boss):**
     - وحش عملاق ثلاثي الأبعاد مع 3 أطوار قتالية (Phases).
     - هجمة الصدمة الأرضية (Ground Slam Shockwave).
     - إطلاق مقذوفات نارية موجهة (Homing Fireballs).
     - طور الغضب (Berserk Roar) واستدعاء حراس إضافيين عند انخفاض صحته.

4. **تحكم متكامل لشاشات اللمس في الآيفون (Mobile Touch Controls):**
   - عصا تحكم افتراضية (Virtual Joystick) للحركة السلسة.
   - منطقة لمس لتوجيه الكاميرا والتصويب (Aim Trackpad).
   - أزرار لمس مريحة: إطلاق النار (Fire)، إعادة التعبئة (Reload)، تبديل السلاح (Switch)، وإنعاش الفريق (Revive).

## 🚀 كيفية رفع المشروع على GitHub وبناء ملف الـ IPA تلقائياً

### الخطوة 1: إنشاء مستودع جديد على حسابك في GitHub
1. افتح [GitHub.com](https://github.com) وسجّل دخولك.
2. اضغط على **New Repository**.
3. سمّ المستودع مثلاً: `TitanStrike-iOS`.
4. اجعله **Public** أو **Private** واضغط **Create repository**.

### الخطوة 2: ربط المجلد ورفع الملفات
في موجه الأوامر (PowerShell / Terminal) داخل مجلد اللعبة:

```bash
git remote add origin https://github.com/YOUR_USERNAME/TitanStrike-iOS.git
git branch -M main
git push -u origin main
```
*(استبدل `YOUR_USERNAME` باسم حسابك على GitHub)*

## 📱 كيف يعمل GitHub Actions لاستخراج ملف الـ IPA؟

بمجرد رفع الملفات إلى GitHub:
1. سيقوم GitHub تلقائياً بتشغيل الـ Workflow الموجود في `.github/workflows/build-ios.yml`.
2. يتم تشغيل خادم **macOS** مزود بنظام Xcode.
3. يقوم الخادم بتصدير اللعبة وتجميع مشروع Xcode وبناء ملف **`TitanStrike-unsigned.ipa`**.
4. عند اكتمال البناء (Build Success)، يمكنك تحميل ملف الـ IPA مباشرة من:
   - تبويب **Actions** في صفحة المستودع.
   - اضغط على أحدث تشغيل (Workflow Run).
   - في الأسفل تحت قسم **Artifacts**، ستجد ملف **`TitanStrike-iOS-IPA`** جاهزاً للتحميل!

## 📲 طريقة تثبيت ملف الـ IPA على الآيفون

بما أن الملف بصيغة `.ipa` غير موقّع بشهادة أبل الرسمية، يمكنك تثبيته بكل سهولة مجاناً بإحدى الطرق التالية:

1. **برنامج Sideloadly (الكمبيوتر -> الآيفون):**
   - حمّل [Sideloadly](https://sideloadly.io/) على جهاز الكمبيوتر.
   - صِل الآيفون بالكمبيوتر بواسطة كابل USB.
   - اسحب ملف `TitanStrike-unsigned.ipa` إلى Sideloadly وضع حساب Apple ID الخاص بك واضغط **Start**.
   - مبروك! سيظهر تطبيق اللعبة فوراً على شاشة هاتفك.

2. **برنامج AltStore:**
   - ثبّت [AltStore](https://altstore.io/) وافتح الملف من خلاله.

3. **أدوات TrollStore أو Scarlet:**
   - إذا كان جهازك يدعم TrollStore أو تستخدم متجر Scarlet، يمكنك تثبيت الـ IPA مباشرة من الهاتف بدون كمبيوتر.

## 👥 كيف تلعب مع أصدقائك (Co-op Multiplayer)؟

1. اتصل أنت وأصدقاؤك بنفس شبكة الـ Wi-Fi (أو قم بتشغيل Hotspot نقطة اتصال من هاتفك).
2. يقوم اللاعب الأول بالضغط على **Host Squad**:
   - سيظهر له رقم الآي بي الخاص به (مثال: `192.168.1.15`).
3. يفتح باقي الأصدقاء اللعبة على هواتفهم، ويكتبون رقم الآي بي في خانة **Join** ويضغطون على زر الدخول.
4. في شاشة الانتظار (Lobby):
   - يختار كل لاعب شخصيته المفضلة (Assault / Heavy / Scout).
   - يضغط اللاعبون على **Ready**.
   - يضغط الـ Host على **Launch Campaign** لتبدأ المعركة معاً!
